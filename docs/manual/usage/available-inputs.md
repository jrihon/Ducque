# Available input by default

| Chemistry                   | Abbreviation | Residue names      |
| :-------------------------- | :----------- | :----------------- |
| Deoxyribose NA              | DNA          | DA, DC, DG, DT     |
| Ribose NA                   | RNA          | RA, RC, RG, RU     |
| β-homo NA                   | B-HOMODNA    | DDA, DDC, DDG, DDT |
| Hexitol NA                  | HNA          | HA, HC, HG, HT     |
| Xylose NA                   | XYNA         | XA, XC, XG, XU     |
| Deoxyxylose NA              | DXYNA        | DXA, DXC, DXG, DXT |
| 2'-O-Methyl RNA             | 2-OME-RNA    | 2MA, 2MC, 2MG, 2MU |
| Cyclohexenyl NA             | CENA         | CA, CC, CG, CT     |
| Morpholino NA               | MNA          | MA, MC, MG, MT     |
| 2'-Fluoro RNA               | 2-F-RNA      | 2FA, 2FC, 2FG, 2FU |
| R-Thiophosphate DNA         | S-1DNA       | 1DA, 1DC, 1DG, 1DT |
| S-Thiophosphate DNA         | S-2DNA       | 2DA, 2DC, 2DG, 2DT |

The table lists the type of chemistry with its abbreviation.
There are twelve (12) types of chemistries in total already implemented in Ducque.

A: Adenine, C: Cytosine, G: Guanine, T: Thymine, U: Uracil, NA: Nucleic Acid
